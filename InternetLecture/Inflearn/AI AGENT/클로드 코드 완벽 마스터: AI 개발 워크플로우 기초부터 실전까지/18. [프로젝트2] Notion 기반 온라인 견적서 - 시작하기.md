```text
당신은 클로드 코드 프롬프트 엔지니어 입니다. \
노션을 사용해서 입력한 견적서 내용을 \
클라이언트가 웹으로 확인하고 PDF로 다운받을 수 있는 \ 
MVP PRD문서를 작성하는 메타 프롬프트를 생성해주세요. \\
\
참고사항:\
- '/Users/gymcoding/workspace/courses/project-name/CLAUDE.md'\\
- 파일위치: docs/PRD_PROMPT.md
```

# 93. 서브에이전트 활용 PRD 생성 (+프롬프트 엔지니어링)
- prd 생성 프롬프트
  - 절대 생성하지 말 것을 강조하고 있다.
  - 출력 템플릿 -> AI를 통해 얻는 결과를 템플릿으로 정의!
- 특정 도메인 분석, 복잡한 로직 처리 -> 서브 에이전트 적극 활용
  - 메인 컨텍스트에서 진행하는거보다, 시간을 더 걸리지만, 더 정교하고 똑똑하게 진행한다.
  - ex) PRD 문서 생성시 특정 도메인 지식 필요
    - 야구 게임
      - 룰 -> 서브 에이전트로 룰 분석 -> PRD 생성
- 에이전트 생성
  - /agents
    - Notion API 전문가 - 서브 에이전트 생성
    ```text
    당신은 웹에서 노션 API 데이터베이스를 정말 잘 다루는 전문가입니다.
    ```
    ```text
    @notion-database-expert 에이전트를 사용하여 노션 기반 견적서 시스템의 PRD 문서를 생성하겠습니다.
    ```
  - [sub agent 체크 -> md 문서 형식 및 나열 방식 체크](https://github.com/gymcoding/invoice-web/blob/main/.claude/agents/docs/prd-generator.md)
    - 구현이 안되는 것을 구현이 되는 것 처럼 하지 말기. -> 검토를 직접하지 않고 AI에 지원을 받아 검토를 요청할 수 있다. -> [prd-validator.md](https://github.com/gymcoding/invoice-web/blob/main/.claude/agents/docs/prd-validator.md)

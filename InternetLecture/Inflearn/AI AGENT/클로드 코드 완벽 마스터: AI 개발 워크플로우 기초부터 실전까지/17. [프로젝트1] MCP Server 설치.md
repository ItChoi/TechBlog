# 88. 유용한 MCP Servers 설치
- 실무에서 유용하게 사용 가능!
- mcp server
  - context7
    - 프로젝트 문서를 자동 분석 후 필요 정보를 빠르게 찾아준다.
    - [mcp server](https://www.inflearn.com/courses/lecture?courseId=339317&type=LECTURE&unitId=361367)
    - claude mcp add --transport http context7 https://mcp.context7.com/mcp --scope project
  - Sequential thinking
    - [mcp server](https://github.com/modelcontextprotocol/servers/tree/main/src/sequentialthinking)
    - 복잡한 문제 해결 과정을 단계 별로 분석하고 추론하는데 도움을 주는 mcp 서버
      - 복잡한 로직 알고리즘, 디버깅 -> 생각 흐름 체계적으로 정리
      - ex) 당신은 Kotlin, Spring boot 웹 개발 전문가입니다. 현재 프로젝트 코드베이스를 분석해서 클로드 코드 메모리 파일인 @Claude.mc 파일을 최적화해주세요. use sequential thinking
  - shadcnui
    - [공식홈](https://ui.shadcn.com/docs/mcp)
    - ai가 shadcn/ui 컴포넌트를 더 효율적으로 사용할 수 있게 도와준다.
      - npx shadcn@latest mcp init --client claude
      - ex) shadcn ui를 사용해서 간단한 로그인 페이지를 만들어줘. 다음 요구사항을 포함해야해: 1. 이메일 입력 필드 2. 비밀번호 입력 필드 3. "로그인하기" 버튼 4. "회원가입" 링크 5. 전체적으로 카드 형태로 중앙 정렬 - 디자인은 깔끔하고 현대적으로 만들어주고, 반응형도 고려해서 모바일에서 잘 보이도록 해줘. use shadcnui mcp server

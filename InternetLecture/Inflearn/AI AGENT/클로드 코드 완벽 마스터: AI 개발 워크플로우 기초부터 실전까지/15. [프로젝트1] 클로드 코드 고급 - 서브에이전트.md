# 81. 서브에이전트 기초: 코드 리뷰 서브 에이전트
- 클로드 코드 강력한 기능 중 하나 -> 서브에이전트
- 서브 에이전트
  - 특정 유형 작업 처리를 위해 호출 -> 전문 AI 어시스턴트
    - 새로운 기능
    - 코드 리뷰
    - 보안 취약점
    - 테스트
- 서브에이전트 시작 방법
  - /agents 
    - 코드리뷰 agent 생성
    ```text
    코드리뷰를 전문적으로 수행하는 서브에이전트를 생성해주세요! 
    그리고 코드리뷰 서브에이전트는 코드 구현 완료 후에 실행해주세요.
    ```
- 서브에이전트 사용 두 가지 방법
  1. 클로드 코드가 우리 요청을 분석해서, 적절한 서브 에이전트를 자동 호출 -> 요청 프롬프트의 내용, 서브 에이전트의 desc 필드를 활용해서 자동 호출
  2. 명시적 호출 -> 프롬프트 요청시 서브에이전트를 언급하여 요청
     - code-reviewer 서브에이전트를 활용해서 전체 코드 리뷰를 진행해주세요.
- 서브 에이전트는 메인 컨텍스트에서 작업하지 않고 자신만의 컨텍스트에서 작업하고, 결과만 메인 컨텍스트로 전달

# 82. 서브에이전트 심화: 컨텍스트 관리
- 서브 에이전트 주요 이점
  - 컨텍스트 보존
    - 메인 대화 오염 방지 -> 메인 대화에 집중 가능!
  - 전문 지식
    - 복잡한 작업 진행시 자체 컨텍스트를 활용해 전문 도메인 바탕으로, 필요한 정보만 요약해서 메인 컨텍스트에 전달 -> 메인 컨텍스트 효과적인 활용 가능 
  - 재사용성
  - 유연한 권한
    - 코드 리뷰 -> 읽기 권한만 줄 수도 있다.
- 서브에이전트 체이닝
  - 복잡한 워크 플로우 -> 여러 서브 에이전트를 체이닝 하여 해결 가능
    


# 83. 🔥[MISSION 12] 미션 소개🔥
- 서브 에이전트 활용
  - 추천 서브에이전트 아이디어:
    - 코드 품질:
      - code-reviewer - 코드 리뷰 및 개선 제안
      - refactorer - 코드 리팩토링 전담
      - security-checker - 보안 취약점 검사
    - 개발 지원:
      - debugger - 버그 분석 및 해결 
      - test-runner - 테스트 실행 및 수정 
      - doc-writer - 문서 및 주석 작성 
    - 프로젝트 관리:
      - deploy-helper - 배포 준비 및 체크 
      - dependency-manager - 패키지 업데이트 관리 
      - performance-analyzer - 성능 분석 및 최적화
- ai에게 추천 서브 에이전트 추천받기
    ```text
    내 Starter Kit은 [기술 스택]으로 되어있어.
    유용한 서브에이전트 아이디어를 3가지 추천해줘.  
    ```
    ```text
    [역할]을 하는 서브에이전트를 만들어줘.
    
    역할: [무엇을 하는 에이전트인지]
    언제 사용: [어떤 상황에서 사용하는지]
    사용 도구: [필요한 도구들]
  
    예시:
    코드 리뷰를 하는 서브에이전트를 만들어줘.
    
    역할: 코드 품질, 보안, 성능을 검토
    언제 사용: 코드 작성 또는 수정 직후 자동으로
    사용 도구: Read, Grep, Glob, Bash
    ```

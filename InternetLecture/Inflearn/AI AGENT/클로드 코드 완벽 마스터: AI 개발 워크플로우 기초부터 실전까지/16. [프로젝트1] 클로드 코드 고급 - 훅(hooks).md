# 85. 훅(hooks) 활용: 슬랙 알림 추가하기
- 복잡한 작업 요청 -> 작업 시간이 꽤 길다. -> 슬랙 알림
  - 권한 승인 요청
  - 작업 완료
- hooks -> slack webhook -> slack app 알림
- slack webhook 설정
  ```text
  당신은 클로드 코드와 슬랙 웹 훅을 잘 다루는 개발자 입니다.
  Claude Code Hooks과 슬랙 웹 훅을 사용해서 클로드 코드가
  "권한 요청할 때"와 "작업이 완료 되었을 때"
  모바일 슬랙 앱으로 알림을 받을 수 있도록 설정해주세요.
  
  단계별로 생각해주세요.
  ultrathink
  ```
  ```
  SLACK_WEBHOOK_URL 설정을 위해 해야할 사항을 초보자도 알기쉽게 가이드해주세요.
  단계별로 생각해주세요.
  
  ```
